GUIDE

使用说明

1. 先搭结构

「＋ 题目」会同时创建题目页和一页解法。左侧结构可以添加解法页、自定义页、题目目录页，以及独立的「致谢」和「结语」收尾页。每道题自动编号，页眉进度点会标出当前题。

2. 写 Markdown

正文支持标题、列表、引用、表格、代码块、**粗体**、==高亮== 和链接。行内公式写 $...$，独立公式写 $$...$$；工具用 KaTeX 离线渲染。

3. 插图片

在正文工具栏点图片按钮，上传后插入 ![图注](asset:id)；也可以把截图直接粘贴或拖进编辑区。插入后点工具栏的「尺寸」，或直接点预览里的图片：默认等比缩放，取消「等比」后可以分别调宽度和高度；正文图片还能选左/中/右对齐。图文页的主图也有缩放滑块。

4. 检查页面

预览会提示内容是否可能超出 16:9。出现提示时，精简文字、把推导拆到下一页，或改用通栏 / 图文布局。

5. 导出 PDF

点右上角「导出 PDF」，在打印窗口选择「另存为 PDF」、边距无、关闭页眉页脚并开启背景图形。每页固定为 960 × 540 pt。

6. 导出与分享

「导出 JSON」用于备份工程；「导出 TeX」可下载 .tex 源码或包含图片的 ZIP 工程，使用 XeLaTeX 编译，也可导入 Overleaf。导出 PDF 用于分享成稿。所有草稿都保存在自己的浏览器里。致谢页可以填写出题组、验题人、志愿者、参赛选手、教练老师和特别鸣谢；结语页适合写赛后的碎碎念。
